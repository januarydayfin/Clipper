# What can Bargen do?

* It can read and save the following:
    * **AZTEC**
    * **UPC-A** / **UPC-E**
    * **EAN-8** / **EAN-13**
    * **CODE-39** / **CODE-93** / **CODE-128**
    * **ITF**
    * **RSS-14**
    * **RSS_EXPANDED**
    * **QR codes**
    * **Data Matrix**
    * **PDF-417**
* It can also **generate these same barcodes** from entered text.
* It can **display barcodes** for later scanning with a data collection terminal (or any device, for that matter).
* It can **assign tags to barcodes** and filter by them. You can also change the colors of the tags to find them more easily in the list.
* You can **search for barcodes** by name or value in the search bar.
* It also **supports a dark theme** and allows you to **sort by date, name, or frequency of use**.

# Stack:
  * Jetpack Compose
  * Koin
  * Room
  * Zxing scanner
